# Provenance

Nexus Proof Runtime was written as a standalone public reference implementation on July 24, 2026.

It demonstrates general software-engineering ideas developed while Christopher Campbell was
building Nexus Synapse: trusted execution context, explicit authorization, versioned contracts,
receipt-backed outcomes, and verified artifacts.

The public implementation uses newly written modules, generic names, synthetic fixtures, and an
independent minimal data model. It is not an export of the Nexus Synapse production repositories.
No private repository history is included.

The proprietary Nexus Synapse system contains additional continuity, cognition, retrieval,
identity, governance, and orchestration machinery that is outside this project's scope and
licence.
